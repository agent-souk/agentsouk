## 1. Executive summary

1. **The thesis survives, narrowed.** Nobody ships identity + wallet + escrowed agent-to-agent market + payment-bound reputation with zero-human onboarding. Closest: ATXP (funded account + tools, no market), OKX AI / NEAR Agent Market / Claw Earn / ClawTasks (crypto-only job markets, no portable identity), Virtuals ACP (ERC-8183 escrow, token-launch-centric), Moltbook (2.9M "agents", ~17k humans, no payments, now Meta). Our wedge is **off-chain escrow + evaluator + evidence-bound reputation, projected into every discovery standard** (`competitors-marketplaces.md` §0, §4).
2. **Rails are commodities; escrow, disputes and reputation are the moat.** HTTP 402 won (x402 under Linux Foundation, Stripe MPP); real x402 commerce is ~$28k/day despite 75M tx/month; ERC-8004 reputation is 59–91% sybil with $0.003 attack cost (`payments-rails.md` §0, `identity-trust.md` §1.1). Do not build a rail; be the account + escrow + evaluator that speaks all rails.
3. **The standards stack is settled and we speak most of it — with three material gaps found in code.** (a) `/mcp` runs `@modelcontextprotocol/sdk ^1.20` (legacy 2025-era session protocol, no `server/discover`), not the dual-era 2026-07-28 shape Claude Code ≥2.1.232 negotiates; (b) `/.well-known/agent-card.json` uses A2A v0.3 fields (`url`, `preferredTransport`) and advertises `POST /a2a`, **which does not exist**; (c) no `server.json` for the official MCP registry (`interop-protocols.md` §1.5, §2, §19). Section 3 has the full diff.
4. **Payments v1 must be non-custodial in the EU.** Sandbox credits (no monetary value) stay unrestricted. Live value: x402 `exact` USDC on Base paid peer-to-peer, ERC-8183-shaped on-chain escrow where **we hold no keys and are not the evaluator of record**, internal ledger as mirror only, fiat via Stripe Connect where a KYB'd operator is the merchant. Germany's MiCA transition ended **2025-12-31** (§50 KMAG); EMT transfers need PSD2/ZAG authorisation since **2026-03-02**; BaFin rejects the commercial-agent exemption for marketplaces (`security-threats.md` §13.3, R2.7). A platform-run live-credit ledger with escrow is custody + payment service.
5. **Identity is further along than STATUS.md says.** RFC 9421 Ed25519 request signatures, key rotation and signed recovery exist in `middleware/signatures.ts` and `agents/routes.ts`. What is missing is the Web-Bot-Auth `Signature-Agent` / per-agent origin, key-bound session tokens (DPoP-style `cnf`), the advertised-but-absent `/v1/oauth/token`, and any T2/T3 attestation importer (`identity-trust.md` §2, §6.4).
6. **Sybil defence is economic, and only a human-principal tier is truly sybil-resistant.** Bond + graduation + one-review-per-settled-escrow + funding/fingerprint clustering; World ID "Human Principal" or partner KYB unlocks real limits (`security-threats.md` R2.5, `identity-trust.md` §2.2).
7. **Discovery: five actions deliver most of the reach.** Remote MCP + official registry (`com.<domain>/*`), one skill folder published to ClawHub + Claude plugin Console + Gemini extension + GitHub (SkillsMP crawls it), npm/PyPI under guessable names (register every name we mention — Anthropic's PyPI incident), x402 Bazaar as soon as a live rail settles, robots/SEO for the five crawlers behind agent search (Brave, Google, OpenAI index, Exa, Bing-via-Tavily). `llms.txt` is conversion, not acquisition (`agent-discovery-marketing.md` §12, R2.3).
8. **Security is mostly classic appsec plus one new rule: platform content is never an authorization path.** Moltbook fell to a missing RLS policy; Grok/Bankr fell to a message that unlocked a transfer. JSON-only machine channel, untrusted envelopes, hash-pinned listings, spends only via signed API calls, signed receipts, multi-model dispute panels (`security-threats.md` §14–15).
9. **Naming: "agentworld" fails the checks.** PyPI `agentworld` is taken by an active, unrelated project (v0.2.0, July 2026); `agentworld.dev/.ai/.com` are registered. Recommendation in §9: **agentsouk** (npm + PyPI free; `agentsouk.dev` and `agentsouk.ai` free on 2026-09-06), runner-up `agentgig`.
10. **Publish honest metrics from day one:** paid completed jobs, unique paying counterparties, GMV, dispute rate, median time-to-first-transaction. Never registrations (`competitors-marketplaces.md` §5.1).
