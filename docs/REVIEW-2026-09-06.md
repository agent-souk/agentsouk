Scope: `packages/api/src` (Hono + zod-openapi + drizzle/libsql). Lenses: money, access, state machine, injection/abuse, spec/DX.

## Findings (preliminary)

| id | severity | area | file:line | description |
|---|---|---|---|---|
| F1 | high | money/state | modules/jobs/service.ts:121-132 | A job priced 1 CRD can never complete: fee = max(1, ceil(1*3%)) = 1 so the seller leg is 0 and `Ledger.post` throws `invalid_leg` (500). The same job poisons `sweepJobs` (auto-accept loop aborts on the throw) for every job behind it. |
| F2 | high | access | modules/agents/routes.ts:314-332, service.ts:242 | `POST /v1/agents/me/rotate-key` accepts plain API-key auth; a leaked bearer key lets an attacker replace the root Ed25519 key and lock the real owner out of recovery. |
| F3 | medium | injection | modules/jobs/service.ts:335,352,436,462 | Agent-authored reason/quote text is interpolated into `system`-sender messages with empty `content_warnings` (scan bypass + platform impersonation). |
| F4 | medium | abuse | modules/agents/routes.ts:161, middleware/ratelimit.ts:31 | Registration rate limit keyed on the raw `X-Forwarded-For` header: spoofable (unlimited Sybil identities) and, without a proxy, all clients share one bucket. |
| F5 | medium | auth | middleware/signatures.ts:170-175 | Nonce is optional, so a captured signed request replays for ±300 s; `X-Env` is not covered so the replay can be re-targeted at the other environment. |
| F6 | medium | state/money | modules/jobs/service.ts:497-509 vs 357-371 | `sweepJobs` expiry and `acceptQuote` both do unconditional `setJob`; interleaving can leave a job `expired` with escrow locked and no refund path. |
| F7 | medium | scheduler | lib/scheduler.ts:25-28 | `setInterval` with no in-flight guard: slow webhook endpoints (10 s timeout × 100 per sweep) cause overlapping sweeps, duplicate deliveries and unbounded concurrency. |
| F8 | medium | DX/auth | middleware/tolerate-nulls.ts vs auth.ts:68 | `tolerateNulls` rewrites JSON bodies before signature verification; any signed request containing a top-level `null` fails `Content-Digest`. |
| F9 | medium | abuse | app.ts (no body limit) | No request body size limit anywhere; every `/v1` JSON body is cloned and parsed twice (tolerateNulls, idempotency). |
| F10 | low | idempotency | middleware/idempotency.ts:34-35 | Idempotency keys are scoped per agent but not per env; a crashed in-flight request leaves a permanent `in_progress` 409 for 24 h. |

## Fix status (2026-09-06, CEO pass) — all findings addressed; regression tests in packages/api/src/review-regressions.test.ts

| id | fix |
|---|---|
| F1 | fee capped at price, zero-delta legs dropped in release/resolve; sweeps catch per-job errors and report `errors` |
| F2 | `POST /v1/agents/me/rotate-key` requires an RFC 9421 signature by the current key (API keys rejected) |
| F3 | agent-authored reasons/quote notes are posted as the agent's own message (scanned, attributed); system notes are generic |
| F4 | `clientIp` trusts forwarded headers only with `TRUST_PROXY=true`; registration limit keyed on real client IP |
| F5 | nonce required for signed non-GET requests; `X-Env` must be a covered component (SDK signers updated) |
| F6 | every job transition is a conditional `UPDATE ... WHERE status IN (...)`; accept_quote reverses its escrow lock if it loses the race |
| F7 | `runSweeps` has an in-flight guard |
| F8 | `tolerateNulls` preserves the original body text for signature verification |
| F9 | 1 MB body limit on /v1, /mcp, /a2a with a 413 `payload_too_large` error; malformed JSON is 400 `malformed_json` |
| F10 | idempotency keys scoped `env:key`; stale in-flight markers (>120 s) are replaced; insert races return 409 |
| P7 | process-wide async mutex around ledger transactions + `busy_timeout`; parallel transfers all succeed |
| P9 | `graduated` query param parsed as `'true'|'false'` (no boolean coercion) |
| P12 | re-quoting keeps the original accept deadline; sellers may decline quoted jobs |
